## Deep Analysis

코드베이스를 깊이 분석합니다. 2명의 전문가를 **병렬 호출**하여 다각도로 분석합니다.

### 사용법

```
consult_experts_parallel({
  experts: [
    { expert: "strategist", message: "다음 코드/시스템을 깊이 분석해줘: [분석 대상]" },
    { expert: "metis", message: "이 문제를 단계별로 분해해줘: [분석 대상]" }
  ]
})
```

단일 전문가로 충분한 경우:

```
consult_expert({
  expert: "strategist",
  message: "다음 코드/시스템을 깊이 분석해줘: [분석 대상]",
  context: "프로젝트 컨텍스트 정보"
})
```

### 분석 단계

1. **구조 분석**: 파일 구조와 모듈 의존성 파악
2. **아키텍처 패턴 식별**: 디자인 패턴과 아키텍처 스타일 분석
3. **의존성 그래프**: 핵심 의존성과 순환 참조 탐지
4. **잠재적 문제점**: 성능 병목, 보안 취약점, 유지보수 어려운 코드 식별
5. **개선 제안**: 구체적이고 실행 가능한 개선안 제시

### 출력 형식

- 분석 결과를 마크다운 표와 목록으로 정리
- 심각도별 우선순위 부여 (Critical / High / Medium / Low)
- 각 문제에 대한 코드 위치와 수정 방향 포함
