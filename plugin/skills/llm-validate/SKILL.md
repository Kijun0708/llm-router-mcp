## Code Validation (코드 검증)

코드를 작성하거나 수정한 후, **반드시 다음 검증을 수행**합니다.

### 필수 검증 단계

#### 1. 빌드/타입 체크

코드 파일을 Write 또는 Edit한 후, 반드시 빌드 또는 타입 체크를 실행합니다:

**TypeScript 프로젝트:**
```bash
npx tsc --noEmit
```

**JavaScript 프로젝트 (ESLint 있는 경우):**
```bash
npx eslint --no-error-on-unmatched-pattern [수정한 파일]
```

**Python 프로젝트:**
```bash
python -m py_compile [수정한 파일]
```

빌드 에러가 발생하면 **즉시 수정**합니다. 다음 작업으로 넘어가지 마세요.

#### 2. 변수명 참조 확인

코드 작성 시 다음을 항상 확인합니다:

- **정의되지 않은 변수 사용**: 변수를 참조하기 전에 해당 스코프에서 정의되었는지 확인
- **잘못된 import 경로**: import할 파일이 실제 존재하는지, export 이름이 정확한지 확인
- **오타/대소문자 불일치**: 변수명, 함수명, 프로퍼티명의 정확한 스펠링 확인
- **스코프 문제**: 블록 스코프 변수를 외부에서 참조하지 않는지 확인

#### 3. 참조 무결성 확인

기존 코드를 수정할 때:

- **이름 변경 시**: 해당 이름을 사용하는 모든 파일에서 같이 변경했는지 Grep으로 확인
- **함수 시그니처 변경 시**: 호출하는 모든 곳의 인자가 일치하는지 확인
- **export 변경 시**: import하는 모든 파일이 올바른지 확인
- **타입/인터페이스 변경 시**: 구현체가 새 인터페이스를 준수하는지 확인

### 자동 실행 조건

이 검증은 다음 상황에서 자동으로 수행됩니다:
- 새 파일 생성 후
- 기존 파일 수정 후
- 리팩토링 (이름 변경, 파일 이동) 후
- 의존성 추가/제거 후

### 오류 발견 시 대응

1. 빌드 에러 출력을 분석
2. 에러 위치의 코드를 확인
3. 원인 파악 (오타, 누락된 import, 잘못된 참조 등)
4. 즉시 수정 후 다시 빌드 체크
5. 모든 에러가 해소될 때까지 반복
