## Research Topic

기술 리서치를 수행합니다. `research_topic` MCP 워크플로우 도구를 사용하세요.

### 사용법

```
research_topic({
  topic: "조사할 주제",
  depth: "normal",
  focus_areas: ["성능", "호환성", "커뮤니티"]
})
```

**깊이 옵션:**
- `quick` — 핵심 정보만 빠르게 (1-2분)
- `normal` — 일반적인 리서치 (3-5분)
- `deep` — 심층 분석, 대안 비교 포함 (5-10분)

또는 `consult_expert`로 직접 전문가를 호출:

```
consult_expert({
  expert: "strategist",
  message: "다음 주제를 조사해줘: [주제]"
})
```

### 탐색 범위

1. **공식 문서 분석**: 핵심 API, 설정 옵션, 모범 사례
2. **사용 패턴**: 일반적인 사용법과 고급 패턴
3. **호환성**: 버전 호환, 의존성, 마이그레이션 가이드
4. **대안 비교**: 유사 라이브러리와의 장단점 비교
5. **실제 예제**: 실용적인 코드 예제 제공

### 출력

- API 핵심 요약 (주요 함수/클래스)
- 설치 및 설정 방법
- 코드 예제 (기본 + 고급)
- 주의사항 및 알려진 이슈
