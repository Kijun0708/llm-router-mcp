## Design Workflow (설계 워크플로우)

여러 전문가가 협업하여 시스템/기능 설계를 수행하고, plan 모드로 구현 계획을 수립합니다.

> **자동 호출 시 확인 필수**: 이 스킬이 상황에 적합하다고 판단되면, 바로 실행하지 말고 먼저 사용자에게 "여러 전문가(GPT, Gemini, Claude)가 협업하여 설계를 진행할 수 있습니다. 진행할까요?"와 같이 확인을 구한 후 실행하세요.

### 실행 흐름

#### 1단계: 전문가 설계안 수집

`design_with_experts` MCP 도구로 전문가들의 설계안을 수집합니다:

```
design_with_experts({
  task: "사용자 인증 시스템 설계",
  include_research: true,
  include_review: true
})
```

**전문가 역할:**
1. **전략 설계** (`strategist`): 아키텍처, 컴포넌트 구조, 기술 선택
2. **리서치** (`researcher`, 선택): 관련 기술/라이브러리 조사, 모범 사례 수집
3. **리뷰** (`reviewer`, 선택): 설계안의 품질, 보안, 확장성 검토

#### 2단계: plan 모드 진입

전문가 설계 결과를 기반으로 **plan 모드에 진입**합니다:
- 전문가들의 설계안을 종합하여 구현 계획을 작성
- 파일별 변경 사항, 구현 순서, 의존 관계를 명확히 정리
- 주의사항 및 리스크 항목 포함

#### 3단계: 사용자 승인

plan 파일을 사용자에게 보여주고 승인을 요청합니다:
- 사용자가 수정/보완을 요청하면 plan 수정
- 승인되면 plan에 따라 구현 시작

#### 4단계: 구현

승인된 plan에 따라 순서대로 구현합니다:
- 각 파일 변경 후 빌드/타입 체크 실행
- plan의 각 항목 완료 시 TodoWrite로 진행 상황 추적

### 옵션

| 파라미터 | 기본값 | 설명 |
|---------|-------|------|
| `include_research` | `true` | 리서치 단계 포함 여부 |
| `include_review` | `true` | 리뷰 단계 포함 여부 |

### 사용 시나리오

- 새 프로젝트 아키텍처 설계
- 기존 시스템 리팩토링 계획
- API 설계
- 데이터베이스 스키마 설계
- 마이그레이션 전략 수립
