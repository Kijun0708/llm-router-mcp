## GPT 위임 설계 (Claude 설계 → GPT 전체 구현)

Claude는 **설계만** 하고, **코드 작업은 전부 GPT에게 위임**합니다.

### 실행 흐름

#### 1단계: 분석 & 설계 (plan 모드)

plan 모드에 진입하여 사용자 요청을 분석합니다:
- 관련 파일을 Read/Glob/Grep으로 파악
- 아키텍처, 파일 구조, 인터페이스 설계
- **코드를 직접 수정하지 않음** (설계만)

plan에 반드시 다음 섹션을 포함하세요:

```
## [GPT 서브태스크]

### 서브태스크 1: (설명)
- 대상 파일: ...
- 변경 내용: ...

### 서브태스크 2: (설명)
- 대상 파일: ...
- 변경 내용: ...
```

#### 2단계: Claude 설계 검토 (Agent 도구 사용)

plan이 완성되면 **구현을 시작하기 전에** Claude가 `Agent` 도구를 사용해 설계 검토를 시도합니다.

설계 규모에 따라 검토 에이전트 수를 결정합니다:

| 설계 규모 | 파일 수 | 검토 에이전트 수 |
|--------|---------|-----------|
| 소 | 1~2개 | 1 |
| 중 | 3~5개 | 2 |
| 대 | 6개+ | 3 |

검토 요청에는 다음 내용을 포함합니다:
- 설계 요약
- 파일 분할 방식
- 서브태스크 독립성
- 인터페이스/데이터 흐름
- 예상 리스크와 테스트 포인트

검토 범위:
- 파일 분할이 적절한지
- 서브태스크 간 의존성이 없는지
- 인터페이스/데이터 흐름이 모순 없는지
- 빠진 예외 처리, 테스트 포인트, 통합 리스크가 없는지

검토 결과 처리:
- **이상 없음**: 다음 단계로 진행
- **문제 발견**: plan 모드로 돌아가 설계를 수정한 뒤 다시 검토

#### 3단계: GPT 설계 전문가 검토

plan이 완성되면 **구현을 시작하기 전에** GPT 설계 전문가에게 설계를 검토받습니다.

검토 범위:
- 파일 분할이 적절한지
- 서브태스크 간 의존성이 없는지
- 인터페이스/데이터 흐름이 모순 없는지
- 빠진 예외 처리, 테스트 포인트, 통합 리스크가 없는지

검토 결과 처리:
- **이상 없음**: 다음 단계로 진행
- **문제 발견**: plan 모드로 돌아가 설계를 수정한 뒤 다시 검토

설계 검토가 끝나기 전에는:
- 사용자 확인을 받지 않음
- `delegate_task`를 호출하지 않음
- 코드를 수정하지 않음

#### 4단계: 서브태스크 분할 기준

작업량에 따라 GPT 에이전트 수를 결정합니다:

| 작업량 | 파일 수 | 에이전트 수 |
|--------|---------|-----------|
| 소 | 1~2개 | 1 |
| 중 | 3~5개 | 2 |
| 대 | 6개+ | 3 |

**중요**: 각 서브태스크는 **독립적**이어야 합니다. 에이전트 간 의존성이 있으면 안 됩니다.

#### 5단계: plan 탈출 → 사용자 확인

plan 모드를 탈출하고 사용자에게 확인합니다:
> "설계 초안, Claude Agent 설계 검토, GPT 설계 전문가 검토를 완료했습니다. GPT Codex 에이전트 N명에게 작업을 위임하겠습니다. 진행할까요?"

사용자에게는 검토 결과를 짧게 요약해서 보여줍니다:
- Claude Agent 검토 결과
- 검토 완료 여부
- 수정 반영 여부
- 남은 리스크가 있으면 1~2줄로 명시

#### 6단계: GPT 위임

`delegate_task` MCP 도구를 호출합니다:

```
delegate_task({
  task: "전체 작업 설명",
  files: ["대상 파일 경로들"],
  context: "plan에서 설계한 내용 발췌",
  context_docs: ["CLAUDE.md"],
  parallel_agents: N,
  agent_tasks: ["서브태스크1 설명", "서브태스크2 설명", ...]
})
```

**모든 에이전트는 병렬로 실행됩니다.**

#### 7단계: 결과 수집

GPT 에이전트들의 리포트를 확인합니다:
- 변경된 파일 목록
- 각 에이전트의 작업 요약
- 발견된 이슈

#### 8단계: 리뷰

변경된 파일들을 리뷰합니다:

```
review_code({
  files: [변경된 파일 경로들],
  context_docs: ["CLAUDE.md"],
  perspectives: 3,
  focus: "all"
})
```

**3관점 × GPT+Gemini = 6 에이전트 병렬로 실행됩니다.**

#### 9단계: 최종 보고

위임 결과 + 리뷰 결과를 종합하여 사용자에게 보고합니다.

### 핵심 원칙

- **설계 완료 후 Claude가 Agent 도구로 설계 검토를 먼저 시도**
- **Claude는 코드를 직접 수정하지 않음** (설계와 리뷰만)
- **설계 완료 후 반드시 GPT 설계 전문가 검토를 먼저 통과**
- **GPT만 코드 변경** (codex --full-auto)
- **2명 이상 호출 시 반드시 병렬** (consult_experts_parallel 또는 delegate_task)
- **Gemini는 리뷰만** (코드 변경 불가)
