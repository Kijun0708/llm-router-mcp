## Component Structure

LLM Router의 특성을 살려 **"고성능 데이터 센터 관제 화면(High-end Terminal / Industrial)"** 컨텍스트를 부여하겠습니다. 장식적인 요소를 배제하고 데이터의 흐름과 상태 변화(Pulse)를 직관적으로 보여주는 데 집중합니다.


## Styling Approach

```css
.fallback-chain-section { grid-column: span 12; }
```

## Accessibility

데이터 갱신이 빈번한 대시보드이므로 스크린 리더와 시각적 대비에 각별히 신경 써야 합니다.

1. **ARIA Live Regions (동적 콘텐츠 알림)**
   - 에러나 Rate Limit 발생 시 즉각적으로 알리도록 설정합니다.
   ```tsx
   <div 
     aria-live="assertive" 
     aria-atomic="true" 
     className="visually-hidden"
   >
     {newRateLimitWarning ? `Rate limit reached for ${model}. Retrying in ${time} seconds.` : ''}
   </div>
   ```

2. **Color Contrast (명도 대비)**
   - 백그라운드(`#0a0a0c`) 대비 텍스트(`var(--text-main)` `#f0f0f5`)는 비율이 **18:1** 이상으로 WCAG AAA 등급을 충족합니다.
   - Muted 텍스트(`#8a8a9e`) 역시 백그라운드 대비 **5.8:1**로 AA 등급을 충족합니다.
   - 색상(Red/Green)에만 의존하지 않고, 항상 아이콘이나 텍스트 라벨(예: `[Running]`, `[Blocked]`)을 병기하여 색약자도 상태를 인지할 수 있게 합니다.

3. **Motion (애니메이션 제어)**
   - 반짝이는 효과나 흐르는 애니메이션은 피로감을 줄 수 있습니다.
   ```css
   @media (prefers-reduced-motion: reduce) {
     .status-dot.active {
       animation: none;
       /* 애니메이션 대신 정적인 굵은 테두리로 상태 표시 */
       border: 2px solid var(--accent-green);
     }
     .fallback-edge {
       animation: none;
       /* 흐르는 선 대신 점선으로 폴백 경로 표현 */
       background: transparent;
       border-top: 2px dashed var(--border-subtle);
     }
   }
   ```
